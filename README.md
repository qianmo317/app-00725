# 数据应用门户网站

基于 Layui + ECharts + OpenLayers + GrapesJS 构建的数据应用门户网站，实现统分结合的个性化数据工作台。

## How to Run

### 方式一：Docker 部署（推荐）

```bash
# 进入项目目录
cd label-00725

# 构建并启动服务
docker-compose up --build -d

# 查看服务状态
docker-compose ps

# 停止服务
docker-compose down
```

### 方式二：本地开发

```bash
# 进入前端目录
cd label-00725/frontend-portal

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 题目内容

### 项目背景与核心定位

打造赋能于业务的"数字前台"，解决两大核心痛点：

1. 业务需求至系统上线的链路长、周期慢
2. 固定的门户内容无法满足员工个性化、动态变化的用数需求

### 核心功能

#### 1. 首页工作台

- **固定卡片区**：核心数据驾驶舱、数字化转型时间轴、统一通知公告、快捷入口
- **可拖拽卡片区**：用户可自由拖拽、配置各类数据卡片，实现"千人千面"

#### 2. 卡片工厂

- 支持多种图表类型：折线图、柱状图、饼图、面积图、雷达图、仪表盘
- 可视化配置：数据源、样式、交互等
- 实时预览与代码导出

#### 3. 应用广场

- 模板市场：浏览、搜索、克隆他人分享的应用模板
- 发布功能：将个人配置的工作台发布为模板供他人使用
- 促进最佳实践的快速复制与创新孵化

#### 4. 低代码设计器

- 基于 GrapesJS 的可视化页面设计器
- 拖拽式组件编排
- 支持预览、保存、导出

#### 5. 地图服务

- 基于 OpenLayers 的地理数据可视化
- 分支机构分布展示
- 区域业务统计

### 技术栈

- **前端框架**：原生 JavaScript + ES6 Modules
- **UI 组件库**：Layui 2.9.x
- **图表库**：ECharts 5.x
- **地图库**：OpenLayers 8.x
- **低代码引擎**：GrapesJS 0.21.x
- **拖拽排序**：SortableJS
- **构建工具**：Vite 5.x
- **样式预处理**：Sass/SCSS

### 设计理念

#### "统分结合"的界面设计

- **"统"的平台权威性**：首页核心区域设置不可移动、不可删除的固定卡片
- **"分"的个性化赋能**：在非锁定区域，员工可自由拖拽、配置各类数据卡片

#### 数据应用场

- 可视化卡片工厂：支持多数据源关联分析
- 场景应用广场：模板分享与克隆
- 低代码原型工具：快速响应复杂需求
